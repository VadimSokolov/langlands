Code for "On Langlands Conjectures: Probabilistic Methods" (Polson and Sokolov)

Requirements: Python 3 with numpy, scipy, matplotlib, mpmath, networkx, cypari2 (PARI/GP 2.15 or later),
and python-flint for the certified computations. ss_graph.gp builds supersingular isogeny graphs from
modular polynomials over F_{N^2}; scripts load it with read("ss_graph.gp") (adjust the path).

book_build/          stage1.py to stage9d.py: the computations behind the figures and tables of the main
                     book (Frobenius traces, Sato Tate and Chebotarev statistics, Ihara zeta and isogeny
                     graphs, Euler products and Thorin computations, log correlated fields, arithmetic
                     statistics, Kloosterman sums); compute.py, figs.py, figs2.py, fig3.py, fig3b.py,
                     fig9.py, fig_parabola10b.py, etacheck.py: further figures and checks; cover.py: cover.
book_figscripts/     per chapter figure scripts (Chapters 3, 6, 11, 12).
ch17_reciprocity/    Chapter 17, Reciprocity through the Swap: recip_compute.py (Polya kernels, Galois heat
                     trace, Gamma shapes), recip_figs.py, recip_gauss.py and recip_gauss_fig.py (Gauss sum
                     reciprocity, Brownian limit, Fejer route), recip_law.py and recip_law_fig.py
                     (Frobenius distances, couplings, conditional means).
ch17_gamma_process/  Section 17.4 and the note "New Reciprocity Theorems": data.py (Frobenius classes and
                     labels for the primes below 1e7; writes data.npz, run first), laws.py (Gamma process
                     and GGC limits, zero probabilities), second.py and fig_second.py (Euler Kronecker
                     drift), heat.py (heat flow Gauss sum reciprocity), figs.py.
ch18_hitting/        Chapter 18, Hitting Times and Reciprocity: graphs.py (Kemeny constants, spanning trees
                     and Kirchhoff index against modular symbols), sandpile.py (critical groups),
                     test37.py (Conjecture 18.5 at N = 37), fig_graph.py (G_157(2) with a Wilson tree),
                     hitrates.py (Chebotarev hitting rates; needs ch17_gamma_process/data.npz),
                     explosion.py and expl_frob.py (mean explosion times from zeros and from Frobenius),
                     exitcheck.py (signed exit law), figs.py; iso.gp, iso_run.py, snf_run.py, other.py.
open_problems/       the open problems notes: certified Patie and Thorin computations (python-flint),
                     Patie survey, Kemeny series and isogeny walk models, spectra and form factors,
                     window tests, reference prior simulation, figures.
scratch/             debugging scripts kept for completeness.

How to run: run each script from inside its own folder (for example cd ch18_hitting; python3 graphs.py).
Shared inputs and outputs live in work/: ss_graph.gp is there, data.npz is written there by
ch17_gamma_process/data.py (run it first), and book figures go to work/figs/. Chapter figures are written
to a figs/ subfolder of each script folder. All paths are relative; nothing refers to the original machine.

Large data files (data.npz, *.npy) are not included; they are regenerated by the scripts.
Checked: every script compiles; test37.py, exitcheck.py, recip_gauss.py and second.py were rerun from
this layout and reproduce the numbers in the chapters.

Note added 2026-10-11, when this archive (the portable version sent with the update of 11 October) was put in the book's project folder as code/: book_build/stage1.py and book_build/figs.py carry two fixes made in the October 2026 review (stage1.py: the Kolmogorov statistic of tau uses both steps of the empirical distribution function, 0.6460, where stage1.json holds the one sided value 0.6424; figs.py: in the CM panel of satotate.pdf the histogram of the nonzero a_p/sqrt(p) is normalised to its mass, about 1/2, to match the curve .5*arc). Every other file is as the coauthor sent it. The scripts for Chapters 17 and 18 are also kept in recip/ and hitting/ at the project root, next to their JSON outputs, as the chapter packages sent them, with their original paths.
